# 2026-08-20 DTrack 工作日志

## 新增 Web 管理平台（Vue3 + Element Plus + Pinia + 后端 stdlib + SQLite）
用户需求：在 DTrack 上加 Web 界面，覆盖白名单管理、项目管理、三方组件库、仓库配置，并实现：
- 白名单/项目以 pom 文件或 gitlab 拉取导入，以 pom 自身 `<version>` 作为版本标识、多版本管理。
- 导入后对所有三方组件及传递依赖做奇安信漏洞扫描，结果存入三方库；白名单导入标记「白名单组件」，项目导入的非白名单组件标记「非白名单」。
- 组件库展示名称/公司/版本/license/漏洞，详情含漏洞详情、所属白名单版本、被哪些项目（版本）使用。
- 后台 SQLite 存储；gitlab/nexus/harbor/maven/奇安信参数界面可配（写回 dtrack.toml）。
- 白名单/项目基于版本的扫描结果报表导出（md 下载，复用原 render_markdown）。

### 后端（纯 stdlib，新增 dtrack/web/，保持离线零依赖）
- `store.py`：sqlite3 建表（config_mirror / whitelist(+_version) / project(+_version) / component / component_usage / vulnerability）。component 表 coord 唯一、is_whitelist 标记；component_usage 记录组件被哪些 whitelist/project 版本以 direct/transitive 引用；vulnerability 按 (component_id, vuln_key) 去重。提供按坐标/关系的查询（含 get_component_detail：漏洞 + 所属白名单版本 + 使用项目）。
- `service.py`：WebService。导入编排复用 `JavaAnalyzer.analyze()` 解析 pom（含传递依赖，自动剔除 test 作用域/测试框架），pom 自身坐标作为 owner 版本标识；扫描复用 `QianxinSource.query()`（组件坐标查询，即「奇安信扫描模式」），后台线程更新状态（pending→scanning→done/no_qianxin/failed）；配置读写回写 dtrack.toml（_to_toml）。报表用 `render_markdown`。
- `handlers.py` + `server.py`：基于 `http.server` 的 REST 路由（/api/whitelists、/api/projects、/api/components、/api/config、/api/gitlab/projects、报表下载）与静态托管（web/dist，SPA fallback）。
- `cli.py`：新增 `dtrack web --host --port --db --config --dist` 子命令。

### 前端（web/，Vite + Vue3 + Element Plus + Pinia + Vue Router）
- 结构分层：api 层（src/api/index.js，fetch 封装+报表下载）、pinia stores（whitelist/project/component/config 4 个）、视图（Whitelist/Project/ComponentLib/Config）、组件（ImportDialog 导入弹窗、ComponentDetailDrawer 详情抽屉）。**视图只渲染，逻辑下沉到 api/store**。
- 导入弹窗支持 POM 文件上传/粘贴 或 GitLab 项目选择（分支可选）；列表可展开多版本、触发扫描、导出 md、删除；组件库带筛选（搜索/类型/漏洞等级）+ 详情抽屉（漏洞 + 白名单版本 + 使用项目）；配置页编辑仓库与奇安信参数。
- `npm install`（npmmirror）+ `npm run build` 产出 web/dist。
