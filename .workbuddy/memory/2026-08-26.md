## 完成：修复导入弹窗 circular structure to JSON 报错

现象：用户截图显示「导入失败：Converting circular structure to JSON ...」，Vue ref 响应式对象被序列化。

根因：`ImportDialog.vue` 的 `submit()` 在 harbor/docker 分支构造 payload 时写了 `source`（ref 对象），
而不是 `source.value`。JSON.stringify 遇到 Vue ref 的响应式依赖图即报循环引用。

修复：`payload = { source: source.value, image_url: imageUrl.value.trim() }`。

验证：前端 rebuild；起 Web 服务用 Python 客户端 POST `/api/projects/import` 传 harbor payload，
返回 201，无 JSON 序列化错误。全量 91 单测仍通过。
